### 核心特性清单 (V1.0 · UX 对齐 2026-03-15)

**1. Issues 核心管理**

- **基础维护**：Issues 的增、删、改、查与目标分解。
- **状态管理**：支持拖拽或自动状态轮转（状态枚举对齐 Linear 标准，并**新增 `Blocked/异常挂起` 状态**，用于标记 Agent 执行卡点）。
- **属性管理**：Issues 标签（Tag）与优先级（Priority）的设置与修改。
- **多维视图**：支持按“状态模式（看板）”与“优先级模式（Eisenhower）”查看和过滤 Issues。
- **任务详情**：在任务详情页配置子任务拆解、优先级、标签、调度与进程参数。
- **创建入口**：全局「新建任务」弹窗，字段包含 Workspace、标题、优先级、标签、描述与定时触发开关。

**2. 运行过程与会话监控 (集成 Symphony 调度与 UI 呈现)**

- **调度触发**：Issue 进入 Todo 状态后自动触发 Agent 运行。
- **并发与排队**：支持配置最大并发数，超额任务根据 Issue 优先级自动排队。
- **状态同步**：看板列表中的运行状态实时刷新。
- **Web 会话视图**：独立页面查看单次运行详情，包含嵌入式 OpenCode Web 会话区域，用于展示 Diff、变更文件与日志。
- **异常与重试机制**：
  - 任务遇到无法解决的卡点时，自动终止并流转至 `Blocked` 状态等待人工介入（仅改变状态，无交互式问答）。
  - 支持配置单次运行的超时熔断。
  - 支持在 Blocked 视图中触发“手动重试 / 补充上下文 / 接管”。

**3. Review 与 Proof of Work**

- **Review 视图**：展示 Agent 总结、Diff 概览与测试/CI 证据。
- **人工决策**：支持“通过/打回/接管”等明确操作路径。

**4. 标签与工作流引擎**

- **标签维护**：标签的基础增删改查。
- **工作流绑定**：标签与具体的执行策略（`workflow.md`）强绑定。
- **可视化编排**：提供可视化的工作流（Workflow）配置界面，支持生命周期钩子。
- **数据源扩展**：支持自定义开发和接入不同的 Issues 数据源。

**5. 工作区与上下文管理**

- **工作区接入**：支持直接从 Opencode 拉取/获取已有工作区。
- **工作区创建**：支持手动添加和配置新的工作区（关联特定代码路径）。
- **工作区管理**：提供工作区列表、快速入口与运行状态提示。
- **全局规则注入**：支持在工作区级别配置全局上下文（如项目说明、编码规范），确保 Agent 每次执行该工作区的任务时默认携带这些背景知识。

**6. 全局设置**

- **MCP 服务提供**：提供 MCP 服务，让 agent 直接通过 MCP 对看板上的任务进行增删改查。

**7. 全局导航与视图切换**

- **全局侧边栏**：Boards / Workspaces / Tags / Settings 导航入口。
- **视图切换**：看板视图与优先级视图之间快速切换。
