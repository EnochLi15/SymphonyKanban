# 把 Symphony Kanban 拆成可以做的任务：从 PRD 到 Issue 列表

> 阶段对应：需求分解 + 开发与测试的准备

## 输入
- PRD 文稿 + 架构设计篇
- 自己实际的开发节奏与时间约束

## 使用的 skills / 方法
- `prd`：从 PRD 提取功能模块和约束
- （预留）任务分解 / issue decomposition skills：辅助拆成具体可执行卡片
- `technical-blog-writing`：形成可读的拆解说明

## 输出
- 前端 / 后端 / 编排 / 执行层的任务清单
- 每个任务的粒度与依赖关系
- 一版可以直接喂给 Symphony Kanban 自己用的 issue 初始列表
