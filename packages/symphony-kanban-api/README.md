# symphony-kanban-api

Express + TypeScript + SQLite API service. Source of truth for issues, events, and execution artifacts.

## Scope
- CRUD + aggregation
- State event log
- Auth/session
- Unified API for web + orchestration

## Structure
- `src/` service source
- `db/` sqlite access layer
