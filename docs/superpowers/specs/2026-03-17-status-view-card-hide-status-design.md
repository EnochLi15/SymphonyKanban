# 状态视图小卡片隐藏“状态”字段 — 设计说明

## 背景与目标
在“状态视图”中，卡片本身已经按状态分组展示，因此卡片内重复展示“状态”字段会造成信息冗余。目标是在状态视图的小卡片中隐藏“状态”字段，同时不影响其他视图（看板视图、优先级视图、详情页等）。

## 范围
- 仅影响“状态视图”的小卡片。
- 其他视图维持现状不变（继续显示状态字段）。

## 方案选择
采用**模板级条件渲染**：卡片组件根据当前视图模式判断是否渲染“状态”字段。

**理由**
- 语义清晰，避免渲染无用 DOM。
- 逻辑集中在卡片组件，避免样式层级的隐式控制。
- 变更最小且易于维护。

## 设计与实现思路
### 组件职责
- 卡片组件应当能够获取“当前视图模式”信息（例如 `viewMode`）。
- 当 `viewMode === "status"` 时，不渲染“状态”字段。
- 其他模式保持原有渲染逻辑。

### 数据流
- 视图容器（状态视图页面）负责传递当前视图模式到卡片组件，或通过已存在的全局/页面状态读取。

### UI 行为
- 在状态视图中，“状态”字段行不渲染、不占位。
- 其他字段保持原有布局与顺序。

## 错误处理与边界
- 若 `viewMode` 未传入或为空，默认保持原行为（显示状态字段），避免意外隐藏。

## 测试要点
- 状态视图：卡片中不显示“状态”字段。
- 看板视图/优先级视图/详情页：状态字段仍显示。
- 未设置视图模式时：保持显示。

## 回滚策略
该改动为纯前端条件渲染，回滚仅需撤销相关条件逻辑即可。
